# MUVSLike — 4인 멀티플레이 뱀서라이크

브라우저에서 바로 즐기는 4인 대전형 뱀파이어 서바이버즈 라이크 게임입니다.
Node.js 권위 서버(WebSocket) + HTML5 Canvas 클라이언트로 동작하며, 빈 자리는 AI가 채웁니다.

**▶ 바로 플레이: https://muvslike.onrender.com** (PC·모바일 브라우저)

## 방 만들기 / 참여

1. 닉네임을 입력하면 **방 목록**이 나옵니다.
2. **방 만들기**로 새 방을 열거나, 목록에서 **참여**(게임 중인 방은 **관전**)를 누릅니다.
   - **비공개** 방은 목록에 보이지 않고 4자리 **방 코드**나 **초대 링크**로만 들어올 수 있습니다.
3. 방 안에서 **초대 링크 복사**를 눌러 친구에게 보내면, 링크를 연 친구는 닉네임만 입력하고 바로 같은 방에 들어옵니다.
4. 방을 만든 사람이 방장이며, 방장이 **게임 시작**을 누르면 빈 슬롯은 AI로 채워집니다.
5. 여러 방이 동시에 각자 게임을 진행할 수 있고, 모두 나간 방은 자동으로 사라집니다.

## 실행

```bash
npm install
npm start            # http://localhost:3000
PORT=8080 npm start  # 포트 변경
```

같은 네트워크의 친구는 `http://<서버 PC의 IP>:3000` 으로 접속합니다.

## 인터넷(웹)으로 공개하기

게임 서버는 WebSocket을 쓰는 Node.js 프로그램이라 GitHub Pages 같은 정적 호스팅에는 올릴 수 없고, Node를 실행할 수 있는 곳이 필요합니다.

### 방법 A. Render 무료 호스팅 (상시 주소, 추천)

1. https://render.com 에 GitHub 계정으로 가입
2. **New → Blueprint** → 이 저장소(`MUVSLike`)와 게임 코드가 있는 브랜치 선택 → **Apply**
   (저장소의 `render.yaml` 설정이 자동으로 적용됩니다)
3. 몇 분 뒤 `https://muvslike-xxxx.onrender.com` 같은 주소가 생기면 그 주소를 친구들에게 공유

- 무료 플랜은 15분간 접속이 없으면 잠들고, 다음 접속 때 깨어나는 데 30~60초 걸립니다.
- 브랜치에 push하면 자동으로 다시 배포됩니다.

### 방법 B. 내 PC에서 서버를 켜고 임시 주소로 공개 (설치 1개, 가장 빠름)

```bash
npm start                                         # 터미널 1: 게임 서버
cloudflared tunnel --url http://localhost:3000    # 터미널 2: 공개 주소 생성
```

`cloudflared` 설치: 윈도우 `winget install --id Cloudflare.cloudflared`, 맥 `brew install cloudflared`.
실행하면 `https://xxxx.trycloudflare.com` 주소가 출력되고, 이 주소로 누구나 접속할 수 있습니다.
PC를 끄거나 명령을 멈추면 주소도 사라지며, 다시 실행할 때마다 주소가 바뀝니다.

### 방법 C. Docker (Fly.io, Railway, Cloud Run, 개인 서버 등)

```bash
docker build -t muvslike .
docker run -p 3000:3000 muvslike
```

호스팅 서비스가 지정하는 `PORT` 환경 변수를 그대로 사용합니다.

### 서버 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 접속 포트 |
| `MAX_CLIENTS` | 40 | 서버 전체 동시 접속 인원 제한 |
| `MAX_ROOMS` | 4 | 동시에 열 수 있는 방 수 (무료 호스팅의 낮은 CPU를 고려한 값) |

상태 확인용 주소는 `/healthz` 입니다.

## 게임 규칙

| 요소 | 내용 |
|---|---|
| 시작 | 4명이 6000×6000 맵의 네 귀퉁이에서 시작. 사람/AI 혼합 가능 |
| 승리 조건 | 맵 중앙의 최종 보스 **심연의 군주**에게 **막타**를 친 플레이어 승리 |
| 보스 봉인 | 보스는 시작 후 8분(설정 가능)간 봉인되어 무적·휴면 상태 |
| 레벨업 | 경험치 보석을 모으면 레벨업 → **게임이 멈추지 않은 채** 3개 중 1개 선택 (1/2/3 키). 선택을 미루면 쌓임 |
| 몹 드랍 | 일반 몹이 가끔 고기(회복)·자석·폭탄·보물상자(추가 선택지)를 떨굼. 오우거는 확률 높음 |
| 오브젝트 | 맵 곳곳의 정예 몬스터 8마리(골렘·비룡·리치). **막타**에 성공하면 강화 아이템(유물) 선택 + 대량 경험치. 일정 시간 후 재등장 |
| PvP | 시작 60초 후부터 플레이어끼리 공격 가능(피해 60%). 처치 시 강화 아이템 선택 |
| 몬스터 분노 | 플레이어가 **다른 플레이어에게 처치될 때마다** 1중첩: 맵 전체 몬스터 공격력 +20%, 중첩마다 **90초 후 만료** (몬스터에게 죽는 것은 해당 없음) |
| 현상금 | 죽지 않고 플레이어를 2명 이상 연속 처치하면 현상금 ★(연속 처치 수, 최대 6). 그 플레이어를 처치하면 ★ 수만큼 **무작위 패시브 강화** (모두 최대면 경험치). 죽으면 현상금 소멸 |
| 부활 | 기본 켜짐: 8초 + 사망 횟수에 따라 증가. 방 설정에서 끌 수 있음(끄면 전원 사망 시 보스 승리) |

중앙에 가까울수록 몬스터가 강해지는 대신 경험치를 더 줍니다. 매 분마다 몬스터 무리가 각 플레이어를 포위합니다.

## 클래스

| 클래스 | 특징 | 고유 무기 | 스킬 (Space/우클릭) | 고유 상태이상 |
|---|---|---|---|---|
| ⚔ 전사 | 근거리 강력, 높은 방어력 | 대검: 넓은 부채꼴 베기 + 넉백 | 회오리 베기: 회전 공격 + 받는 피해 감소 | 출혈 |
| ➶ 소총수 | 강력한 원거리 일반 공격, 중간 방어력 | 소총: 고속 탄환, 레벨업 시 관통 | 수류탄: 조준 지점 폭발 + 넉백 | 약점 노출 |
| ✦ 마법사 | 느리지만 광역 + 상태이상, 취약한 방어력 | 화염구: 폭발, 연소 + 둔화 | 메테오: 지연 후 거대 폭발 + 기절 | 연소 |
| ⚡ 마검사 | 강력한 근거리 마법, 중간 방어력 | 룬검: 마력 베기 + 검기 발사 | 섬광 베기: 순간이동하며 경로의 적 베기 | 서리 |
| ✧ 암살자 | (추가) 빠른 이동, 높은 치명타 | 단검: 다중 투척 | 그림자 걸음: 돌진 후 3초간 치명타 확정 | 중독 |
| ✚ 성기사 | (추가) 최고 체력, 지속 흡수 | 신성 지대: 주변 지속 피해 + 회복 | 천상의 보호막: 무적 + 회복 | 빛의 인장 |

공용 무기(회전 칼날·낙뢰·유도탄·서리 파동)와 패시브 14종, 강화 아이템(유물) 22종이 있습니다.

### 상태이상

| 상태이상 | 효과 |
|---|---|
| 출혈 | 중첩(최대 5) 지속 피해 |
| 연소 | 강한 지속 피해 |
| 약점 노출 | 중첩당 받는 **모든** 피해 +6% (최대 5) — 다른 플레이어의 공격에도 적용 |
| 빛의 인장 | 3초 후 또는 대상 사망 시 신성 폭발(주변 피해) + 시전자 회복. 인장 걸린 적끼리 연쇄 폭발 |
| 중독 | 중첩(최대 8) 지속 피해, 플레이어는 회복량 -40% |
| 서리 | 중첩당 둔화 10%, 5중첩 시 빙결 |

공용 무기도 상태이상을 겁니다(회전 칼날 = 출혈, 서리 파동 = 서리).
상태이상 관련 아이템:

- **부여 유물 (클래스 무관)**: 톱니 칼날(출혈) · 불씨 반지(연소) · 정밀 조준경(약점 노출) · 빛의 성표(빛의 인장) · 독사의 이빨(중독) · 서리 핵(서리) — 적중 시 확률로 해당 상태이상
- **잔혹** (패시브): 대상의 상태이상 1종당 피해 +5%/레벨 (최대 4종)
- **증폭** (패시브): 상태이상 피해·효과 +25%, 지속시간 +15% /레벨
- **역병의 씨앗** (유물): 상태이상에 걸린 적 처치 시 주변 적 3명에게 상태이상 전이
- **연쇄 촉매** (유물): 상태이상을 걸 때 중첩 +1, 상태이상 피해 +30%

흡혈과 빛의 인장 회복은 **초당 최대 체력의 1.2%까지만** 적용됩니다(광역 공격으로 사실상 무한 회복이 되던 문제 방지).

## 조작

- **WASD / 방향키** 이동 · 공격은 자동 (가장 가까운 적 조준)
- **Space / 우클릭** 클래스 스킬 (마우스 방향)
- **1 / 2 / 3** 레벨업·강화 아이템 선택 (카드 클릭도 가능)
- **Q** 타겟 우선순위 전환: 자동 → 몬스터 우선 → 플레이어 우선
- **Tab** 관전 대상 변경 (사망/관전 시) · **Enter** 채팅

**모바일(터치)**: 화면 아무 곳이나 누른 채 드래그하면 그 자리에 가상 조이스틱이 생겨 이동합니다.
오른쪽 아래 원형 버튼이 스킬(가장 가까운 적 자동 조준, 마검사·암살자의 돌진 스킬은 조이스틱 방향 우선)이고,
레벨업 카드는 탭해서 고릅니다. 가로 모드를 권장합니다.

게임 도중 접속한 사람은 관전자가 되며, 화면 왼쪽 아래 버튼으로 AI 플레이어를 **인수**할 수 있습니다.
플레이어가 나가면 그 캐릭터는 AI가 이어서 조종합니다.

## 그래픽

외부 이미지 없이 모두 코드(Canvas)로 그린 밝은 협곡 스타일입니다: 잔디·흙길 레인·강과 다리·정글 숲,
팀 색 수정이 있는 시작 기지, 보라빛 보스 둥지, 바위로 둘러싼 오브젝트 둥지, 클래스별 무기를 든 챔피언,
발광 투사체와 파티클, 레벨 칸이 있는 체력바. UI는 남색 바탕 + 금색 테두리 스타일입니다.
성능을 위해 몹·장식은 미리 그린 스프라이트로, 움직이지 않는 지형은 600×600 조각 단위로 캐시해 그립니다.

## 구조

```
shared/defs.js   클래스·무기·패시브·유물·몬스터·오브젝트 등 모든 밸런스 데이터 (서버/클라이언트 공용)
server/game.js   게임 시뮬레이션 (30Hz 권위 서버, 네트워크와 독립)
server/ai.js     AI 플레이어 (사람과 동일한 입력만 사용)
server/room.js   방 하나(슬롯·방장·설정·게임 진행, 15Hz 시야 기반 스냅샷)
server/index.js  HTTP 정적 서버 + WebSocket 접속/방 목록 관리 + 전체 게임 루프
client/          캔버스 렌더러, 보간/이동 예측, HUD, 로비 UI
test/sim.js      AI 4명 헤드리스 시뮬레이션 (밸런스/성능 확인)
```

```bash
npm test                    # 3분 스모크 시뮬레이션
node test/sim.js --games 5  # 전체 게임 5판 시뮬레이션 + 클래스별 승률/피해 분석
```

밸런스 조정은 대부분 `shared/defs.js`의 수치만 바꾸면 됩니다.
